# e-plantShopping - Paradise Nursery Shopping Application

An online shopping application for **Paradise Nursery**, offering a wide variety of houseplants, air-purifying selections, and aromatic botanicals.

## Overview
**e-plantShopping** is built using React and Redux Toolkit. It allows users to browse different plant categories, view plant details, add plants to a shopping cart, adjust quantities dynamically, and view total costs in real-time.

## Features
- **Landing Page:** Welcoming interface with an introduction and quick transition to the catalog.
- **Product Catalog:** Plants organized into dedicated categories (Air Purifying, Aromatic, Medicinal) with price, description, and status feedback.
- **Cart Management:** Dynamic cart badge in navbar, quantity controls (increment/decrement), item deletion, and subtotal/total calculations.
- **Responsive UI:** Clean and mobile-friendly styling.

## Repository
- **Repository Name:** `e-plantShopping`
- **Built with:** React, Redux Toolkit, Vite
